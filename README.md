# 工资小组件

一个常驻 Windows 桌面的小工具：提前设置月薪、加班基数和工作时间，它会**按秒累计今天已经赚到的钱**，并显示**距离下班还有多久**。

![工资小组件预览](docs/preview-widget.png)

> Windows 10/11 x64 · Electron · 本地数据 · 可选在线节假日接口

## 功能

- **实时收入**：按工作时长逐秒累计，午休、晚休期间自动暂停。
- **下班倒计时**：自动区分未上班、工作中、午休中、晚休中、法定节假日、加班中、休息日。
- **自选工作日**：周一到周日任意勾选普通工作日，默认周一到周五。
- **手动 / 自动加班**：可以点「我要加班」手动开始，也可以勾选工作日/周末自动计算；自动时只显示「我下班啦！」。
- **工作日提前预约加班**：下班前 30 分钟显示「我要加班」，点击只是预约；加班仍从下班时间开始，不会提前计费。
- **逐日周末询问**：从最后一个工作日开始，逐日询问明天是否加班，直到休息日倒数第二天；每次确认只作用于第二天。
- **预约日手动覆盖**：前一天确认第二天加班后，第二天默认按工作日上下班时间结算，也可用「现在开始加班」或「补录开始时间」覆盖。
- **法定节假日**：设置里提供下载网址，人工下载 JSON 后导入，或放进节假日文件夹自动识别；节假日按 3 倍、调休补班按普通工作日计算。
- **在线节假日接口（可选）**：填写天聚数行 API Key 并开启，自动拉取当年数据并按年缓存；自动/手动各最多 3 次成功调用/天。
- **请假**：顶部「⋯」菜单和设置里都可以打开请假月历；一次记录一天，可选有薪假/年假、病假或事假，并可精确到分钟设置开始、结束时间。有薪假/年假、病假按请假时段计薪，病假比例可在设置里调整，事假不计薪。
- **当月薪资报表**：顶部「⋯」→「查看当月薪资」，按月显示每天上下班时间、工时、基础/请假/加班/合计工资，以及上班天数、请假天数和总工时；可切换到上一个月查看。
- **按当月实际工作日计薪**：月薪和加班基数都除以当月实际工作日，不再使用固定的 21.75 天。
- **补班提醒**：如果节假日数据里第二天是调休补班日，点「我下班啦！」后会提示「明天需要补班哦~别忘记了!」；点击提示即可关闭；没有节假日数据时不显示。
- **可改加班倍率**：工作日默认 1.5 倍、周末默认 2 倍、法定节假日默认 3 倍。
- **主窗口贴边自动隐藏**：把主窗口拖到屏幕上/下/左/右边缘，松开后自动吸附并收起为一条进度条；鼠标移到进度条上展开完整主窗口，移开自动收起；最小化到托盘时也会自动收边。可在设置 → 外观里关闭。
- **桌面小组件体验**：无边框圆角、半透明深色卡片、可拖动、可自由缩放、窗口置顶、托盘常驻、开机自启。
- **八种主题色**：暖阳橙（默认）、琥珀金、珊瑚红、樱花粉、紫罗兰、天空蓝、青蓝、薄荷绿。
- **本地保存**：配置和数据只保存在本机；默认不联网，只有主动启用在线节假日接口时才会访问网络。

## 加班规则

- 工作日下班后点「我要加班」：从**当天下班时间**开始补算加班费，即使晚点才点也一样。
- 工作日下班前 30 分钟点「我要加班」：只是预约，仍从下班时间开始计费。
- 周末、法定节假日点「我要加班」：从**下一个整点或半点**开始计费。
- 前一天确认第二天加班后：
  - 第二天默认按工作日的上班/下班时间结算；
  - 「现在开始加班」：从当前时间的下一个整点或半点开始；
  - 「补录开始时间」：选择实际开始时间，从该时间补算；
  - 如果都不点，到下班时间自动结算并高亮。
- 每天只确认第二天，不会一次确认整个周末。

## 请假规则

- 有薪假/年假：按请假时段的正常工资计算；遇到周末/法定节假日会跳过并顺延到下一个工作日。
- 病假：按设置的病假比例乘以请假时段工资；不跳过周末/节假日，但这些天不计薪。
- 事假：请假时段不计薪；遇到周末/法定节假日会跳过并顺延到下一个工作日。
- 请假时间默认是当天的上班到下班时间，也可以精确调整开始、结束时间到分钟。
- 请假当天不显示加班按钮，也不计加班费。
- 请假记录一次只作用于一天，同一天保存会覆盖，也可以取消该天的请假。

## 当月薪资

- 报表保留**当月和上一个月**；再早的月份会自动清理。
- 每天的上下班时间按当前设置的班次显示。
- 工资构成包含基础工资、请假工资、加班费和合计。
- 月薪和加班基数按该月实际工作日折算，报表标题会显示当月工作日数。
- 统计上班天数、请假天数（有薪假/年假、病假、事假分别统计）和总工时。
- 历史月份按当前月薪、加班基数等设置重新计算，不是每月固定快照。

## 数据文件

配置默认保存在 exe 旁边：

```text
userdata\config.json
```

请假和月度报表统计保存在：

```text
userdata\records.json
```

节假日数据放在：

```text
userdata\holidays\2026.json
userdata\holidays-data.json
userdata\holidays-api-cache.json
userdata\holidays-api-usage.json
```

删除 `records.json` 会清空请假和月度报表历史数据。删除配置目录会恢复默认设置。

## 从最小化恢复

- 恢复时会立即重新计算并刷新按钮。
- 高亮和鼓励语只在点击「我下班啦！」确认后出现；仅到下班时间不会自动显示。
- 最小化期间触发的提示，恢复后会补显示；提示显示期间再次最小化，恢复后会重新显示完整提示。

## 计算规则

```text
每日计薪工时 = 下班时间 − 上班时间 − 午休 − 晚休（只扣与工作时间重叠的部分）
时薪         = 月薪 ÷ 当月实际工作日 ÷ 每日计薪工时
今日收入     = 已工作计薪秒数 × 时薪 + 请假工资 + 加班费
工作日加班时薪 = 加班基数 ÷ 当月实际工作日 ÷ 8 × 工作日加班倍率
周末加班时薪   = 加班基数 ÷ 当月实际工作日 ÷ 8 × 周末加班倍率
法定节假日时薪 = 加班基数 ÷ 当月实际工作日 ÷ 8 × 法定节假日加班倍率
```

- 法定节假日中只有法定节假日当天按 3 倍，假期里的普通休息日按周末 2 倍。
- 晚休可以设在下班后，加班计时会自动扣除。
- 未导入节假日数据时按手动勾选的工作日判断。
- 收入是估算值，不包含社保、公积金、个税、奖金、补贴、全勤奖等。

## 本地开发

环境：Windows 10/11 x64、Node.js >= 22.12、pnpm。

```bash
pnpm install --frozen-lockfile
pnpm start
```

## 打包

```bash
pnpm package
```

输出目录：

```text
dist/工资小组件/
```

首次打包时 `@electron/packager` 会下载对应 Electron 版本；如果本地已有
`.electron-zips/electron-v45.2.3-win32-x64.zip`，会自动复用以支持离线打包。

打包结果不包含 `userdata`、API Key 或在线节假日缓存。

## 数据与隐私

默认情况下程序不联网，配置和记录只写入程序旁的 `userdata` 目录：

```text
userdata/config.json
userdata/records.json
userdata/holidays/
```

如果主动开启在线节假日接口，才会请求天聚数行；API Key 使用 Windows 安全存储加密。
仓库和发布包中不应提交任何个人配置、记录、日志或 API Key。

## 已知限制

- 法定节假日数据需要人工下载导入，或启用在线接口；没有数据时按手动勾选的工作日判断。
- 在线接口依赖天聚数行，需要 API Key。
- API Key 使用 Windows 安全存储加密，换到其他 Windows 用户或电脑后需要重新填写。
- 仅支持当天内完成的班次，不支持跨午夜夜班。
